# Club

The Club module and submodules provide custom code for the appearance and functionality of the North Shore Cyclists website.

## Requirements

This module requires Drupal, CiviCRM and contributed modules listed in the site's composer.json.

CiviCRM is open-source Constituent Relationship Management (CRM) software that integrates with Drupal.
